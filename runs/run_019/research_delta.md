# Run 019 research delta — sensitivity-aware C03 screening

Wang et al., “Design method for a desensitized off-axis three-mirror anastigmatic optical system with freeform surface,” *Optics Communications* 575 (2025) 131228, DOI [10.1016/j.optcom.2024.131228](https://doi.org/10.1016/j.optcom.2024.131228), was used as architecture guidance. The publisher record identifies mirror spacing and off-axis magnitude as important sensitivity variables and reports a low-sensitivity design route.

The independently supplied result that the paper's desensitized design was about 60% as sensitive as its nominal-performance-optimized comparison is recorded as literature context, not transferred as a requirement, tolerance, target, or expected C03 result. Run 019 therefore varied mirror spacing and off-axis magnitude while measuring representative tilt/decenter response from the first screen. It did not optimize nominal image quality first and defer sensitivity.

The literature uses an off-axis TMA with a freeform surface; Run 019 deliberately begins with a lower-complexity two-confocal-mirror common afocal front and ideal channel cameras. The systems are not numerically interchangeable. Freeforms were not introduced because the conic-only experiment already established the controlling package, parent-envelope and sensitivity trade, and because a near-parabolic conic refinement improved nominal blur without materially reducing the perturbation response.
